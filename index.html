Hardware Assembly Guide

ESP32 Two-Board Hardware Wiring & Pinout Guide

This system uses TWO separate ESP32 boards (one strapped to each leg), each plugged into its own USB port. No I2C multiplexer is needed since each board only handles 2 IMUs.

Left Leg Board (LEG_SIDE = "left")

  • • Thigh MPU6050 IMU: I2C address 0x68 (AD0 → GND), SDA=21, SCL=22
  • • Shank MPU6050 IMU: I2C address 0x69 (AD0 → 3.3V), same bus
  • • FSR 1 (1st Metatarsal / Medial): Pin GPIO34 (ADC1_CH6)
  • • FSR 2 (5th Metatarsal / Lateral): Pin GPIO35 (ADC1_CH7)
  • • Each FSR: one leg to 3.3V, other leg to the ADC pin + a 10kΩ pull-down to GND.

Right Leg Board (LEG_SIDE = "right")

  • • Thigh MPU6050 IMU: I2C address 0x68 (AD0 → GND), SDA=21, SCL=22
  • • Shank MPU6050 IMU: I2C address 0x69 (AD0 → 3.3V), same bus
  • • FSR 1 (1st Metatarsal / Medial): Pin GPIO34 (ADC1_CH6)
  • • FSR 2 (5th Metatarsal / Lateral): Pin GPIO35 (ADC1_CH7)
  • • Wiring is identical to the left board — only the LEG_SIDE constant in the firmware differs.

Flashing & Connecting

  1. Flash esp32_single_leg_hardware.ino to the LEFT board with LEG_SIDE = "left".
  2. Flash the same file to the RIGHT board with LEG_SIDE = "right".
  3. Plug both boards into USB ports on the same computer/Raspberry Pi.
  4. On the Hardware tab, click "Connect Left Leg USB" and pick the left board's port, then click "Connect Right Leg USB" and pick the right board's port.
